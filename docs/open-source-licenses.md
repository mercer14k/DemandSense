# Open-source components and model licenses

DemandSense source code and generated synthetic fixtures are released under the repository's MIT license. No customer dataset or model weights are included.

The table covers material direct dependencies and runtimes. Exact installed package versions and available license metadata are recorded in [dependency-inventory.json](dependency-inventory.json), generated by `python scripts/license_inventory.py`. Python pins live in `requirements.lock`; web pins and integrity digests live in `apps/web/pnpm-lock.yaml`. That metadata inventory is a starting point, not a full legal compliance audit.

Native Python/Node development requires no container product. No closed-source runtime is necessary for the computational or AI core.

## Open weights are a separate licensing decision

The user selects an already-installed model. No weights are redistributed and no model is downloaded automatically. The verified local example used **Qwen3-8B**, whose upstream [model card declares Apache-2.0](https://huggingface.co/Qwen/Qwen3-8B). The Ollama quantization identity is recorded in the AI benchmark. Other model families can have different licenses and acceptable-use conditions; the runtime's license does not grant rights to every weight it can load. Check the exact model and quantization source before use or redistribution.

When distributing a container or binary, retain the upstream license/copyright notices packaged in installed dependencies. Review LGPL obligations for the PostgreSQL driver and notices for BLAS/LAPACK and other bundled numerical libraries. Do not label every dependency MIT merely because this repository is MIT.
